# EchoNote v1 常见问题

数据目录在下文写作 `<数据目录>`：

- macOS：`~/Library/Application Support/com.rebill.echonote`（在访达里按 Shift-Command-G 输入这个路径）
- Windows：`%LOCALAPPDATA%\com.rebill.echonote`（在资源管理器地址栏输入）

## 安装和启动

**macOS 提示“无法验证开发者”或“已损坏”，打不开。** 安装包没有经过 Apple 公证。按 [安装说明](V1_0_0_DESKTOP_APP_INSTALL.md) 在“隐私与安全性”里点“仍要打开”，或者用 `xattr -dr com.apple.quarantine /Applications/EchoNote.app` 去掉下载标记。

**Windows 提示“Windows 已保护你的电脑”。** 安装包没有签名。校验 SHA-256 后点“更多信息 → 仍要运行”。

**Windows 安装时卡在下载 WebView2。** 这台电脑没有 WebView2 运行时，安装程序要联网下载。离线电脑请先用微软的离线安装包装好 WebView2 运行时，再运行 EchoNote 安装程序。

**提示“资料库来自更新版本的 EchoNote”。** 资料库被新版本升级过，旧版本不能打开。装回新版本即可。每次升级资料库前，应用会在数据目录里留一份备份，文件名是 `library.sqlite3.v<旧版本号>.bak`。

## 录音

**每次更新后 macOS 都询问 EchoNote 能否使用钥匙串。** ad-hoc 签名的应用每个版本的签名都不同。输入登录密码后点“始终允许”。想要更新后不再询问，见安装说明的“自签名构建”。

**提示“没有麦克风权限”。** macOS：系统设置 → 隐私与安全性 → 麦克风，打开 EchoNote。Windows：设置 → 隐私和安全性 → 麦克风，打开“允许桌面应用访问麦克风”。然后重新开始录音。

**只有“我”，没有“对方”。**

- macOS：点提示里的“去系统设置开启”，系统设置会打开系统音频录制权限所在的页面，允许 EchoNote，然后重新开始录音。
- Windows 10：会议软件要从默认播放设备出声。在会议软件里把扬声器设成“默认设备”，或者把常用的耳机设成系统默认播放设备。
- 录音时出现“系统声音录制失败，只录麦克风”时，提示里带有原因，日志里也有记录。

**提示“麦克风录到了扬声器的声音，重复内容已隐藏”。** 用外放时麦克风会录到对方的声音，应用会隐藏重复的内容，但可能漏掉或多删。戴耳机效果最好。

**录音自己停了。** 默认 15 分钟没有人说话会自动停止。在设置里修改“无人说话时自动停止”，设为 0 表示不自动停止。

**快捷键没有反应，或者提示“快捷键已被其他应用占用”。** 在设置里换一个组合键。留空表示不用快捷键。

**会议显示“已恢复”。** 上次录音时应用异常退出（崩溃、断电、强制退出）。重新打开应用后，录音文件已修复，退出前的转录都保留了，没转写完的部分会补转。

## 转录

**提示“没有找到识别模型”或“识别模型加载失败”，录音保存了但没有文字。** 默认模型在应用安装目录里，文件缺失或损坏时会出现这个提示。重新安装应用。录音还在，重装后可以对这场会议做“高精度重转”。

**提示“缺少语音检测模型，无法开始录音”。** 同上，重新安装应用。

**高精度模型下载失败。**

- “下载中断了，可以继续下载”：网络断开。已经下载的部分会保留，再点下载会接着下。
- “磁盘空间不足”：高精度模型约 1 GB，需要再多留 256 MB 余量。
- “下载的文件校验失败”：文件内容不对，应用已经丢弃，重新下载即可。
- 一直连不上：应用依次尝试 ModelScope、Hugging Face 和 GitHub。检查网络和系统代理。

**高精度重转很慢。** 高精度模型在 CPU 上比默认模型慢很多，4 核电脑上可能比会议本身还长。可以随时“停止重转”，下次点击会从停下的地方继续。录音时重转会自动暂停。

**重转后有些段落没变。** 手动修改过的段落、来源不是语音识别的段落、被判为串音的段落不会重转。对结果不满意可以“撤销重转”；撤销不会覆盖你在重转之后修改过的段落。

## AI 功能

**提示“需要先确认把转录发给这个服务”。** 第一次把转录发给一个服务地址前要确认，服务地址变了也要重新确认。本机服务不需要确认。

**提示“API Key 无效或没有权限”“找不到这个模型或接口”。** 在设置里检查服务地址、模型名和 API Key。OpenAI 兼容服务的地址通常以 `/v1` 结尾。

**提示“钥匙串里找不到保存的 API Key”。** 钥匙串项目被删除，或者钥匙串访问被拒绝。在设置里重新填写 API Key。

**提示“只有本机服务可以用 http”。** 局域网里的服务要用 http 时，在服务设置里勾选“允许用 http”。

**提示“转录超出了模型的上下文窗口”。** 在服务设置里把“上下文窗口”调到这个模型的实际大小，长会议会分段总结。

## 反馈问题

日志在 `<数据目录>/logs/app.log`（旧日志是 `app.log.1`）。日志只有事件、错误码和耗时，不含转录文字和 API Key，可以直接附在问题报告里。请同时写明系统版本、芯片类型和操作步骤。

## 从头开始

退出 EchoNote（包括菜单栏或任务栏通知区域的图标），把 `<数据目录>` 改名，例如改成 `com.rebill.echonote.old`，再打开应用。应用会新建一个空资料库。确认不需要旧数据后再删除改名后的目录。
