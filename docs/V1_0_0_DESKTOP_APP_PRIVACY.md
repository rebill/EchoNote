# EchoNote v1 隐私说明

EchoNote 在你的电脑上录音和转写。没有账户，不收集遥测和使用统计，不上传音频。只有你使用下面“联网”一节列出的两项功能时，应用才会连接网络。

## 存在本机的数据

数据目录：

- macOS：`~/Library/Application Support/com.rebill.echonote`
- Windows：`%APPDATA%\com.rebill.echonote`

| 内容 | 位置 | 说明 |
|---|---|---|
| 资料库 | `library.sqlite3` | 会议、转录、修改记录、总结、问答、词表、模板和设置。不含 API Key |
| 录音 | `meetings/<会议 id>/` | 每场会议两条 Ogg/Opus 音轨：麦克风（我）和系统声音（对方） |
| 模型 | `models/` | 在设置里下载的高精度模型。默认模型在应用安装目录里 |
| 日志 | `logs/app.log` | 只记录事件、错误码、计数和耗时，不记录转录文字、提示词、API Key 和请求头的值。超过 1 MB 轮换，保留一份旧日志 |

导出的 Markdown 只写到你在保存对话框里选的位置。

## API Key

大模型服务的 API Key 和需要保密的请求头存在系统钥匙串里：macOS 是登录钥匙串，Windows 是凭据管理器。每个服务一项，名称包含 `com.rebill.echonote`。资料库和日志里只有请求头的名称。删除服务时，它的钥匙串项目一起删除。

## 联网

EchoNote 只在两种情况下联网。

**下载高精度模型**：在“设置 → 语音模型”里点下载时，应用依次尝试 ModelScope、Hugging Face 和 GitHub 发布页，只用 HTTPS。请求里只有文件地址和 `EchoNote/<版本>` 用户代理，不带任何账户或设备信息。下载的每个文件都按内置清单校验大小和 SHA-256。

**使用 AI 功能**：总结、问答和大模型纠错会把这场会议的转录文字（带时间和“我/对方”标记）、你的问题、词表和所选的总结模板发给你配置的服务。

- 第一次把转录发给某个服务地址前，应用会请你确认。服务地址的协议、主机或端口变了，会重新确认。
- 本机服务（`localhost`、`127.0.0.1` 等）不询问，因为数据不出这台电脑。
- 音频永远不会发出。
- 服务怎样处理收到的内容，以服务商自己的条款为准。

应用使用系统代理设置；也可以在服务设置里单独填代理地址。

Windows 安装程序在系统没有 WebView2 运行时的时候会从微软下载安装，这一步由微软的安装程序完成。

## 权限

- 麦克风和系统音频录制权限只在录音时使用，停止录音就释放。
- 拒绝系统音频权限时只录麦克风。

## 删除

- 删除一场会议会同时删除它的录音文件，以及资料库里的转录、修改记录、总结和问答。删除后无法恢复。资料库释放的空间可能保留旧内容，直到 SQLite 复用这些空间为止。
- 删除高精度模型会删除 `models/` 里对应的文件。
- 卸载应用不会删除数据目录。完全清除的步骤见 [安装说明](V1_0_0_DESKTOP_APP_INSTALL.md) 的“更新和卸载”。
